# SKP — Recherche zur Pool-Reform in der Schulbegleitung

Dieses Repository enthält die Rechercheergebnisse zur Umstellung von der 1:1-Schulbegleitung
auf Poolversorgung und deren Auswirkungen auf SKP (Uetersen).

## Inhalt

- [`research/schulbegleitung-poolreform-analyse.md`](research/schulbegleitung-poolreform-analyse.md)
  — Vollständige Analyse: Rechtslage, Landkarte der Poolmodelle in Schleswig-Holstein und
  Hamburg, Fallstudie Kreis Pinneberg („Klassenassistenz"), Antworten auf alle Einzelfragen,
  Fallzahlen und Trends, Risikobewertung, Fahrplan und Quellenverzeichnis.

## Betrachtete Regionen

Kreis Steinburg · Hamburg · Kreis Segeberg · Kreis Ostholstein · Neumünster
(zzgl. Kreis Pinneberg als Referenzmarkt)

## Kernaussage

Das Marktvolumen für Schulbegleitung wächst weiter — Fallzahlen und Ausgaben steigen in allen
belastbaren Datenreihen. Was wegfällt, ist der Zugang über die Einzelfallbewilligung. Künftig
werden Standort- und Regionalverträge vergeben, in der Regel **ein Träger je Schule**.
Entscheidend sind damit Vergabe- bzw. Interessenbekundungsverfahren, eine pädagogische
Koordinations-/Teamleitungsfunktion und die regionale Verankerung bei Schulleitungen.

Stand der Recherche: Juli 2026.
